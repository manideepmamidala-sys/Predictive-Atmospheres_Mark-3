# Release-readiness record

**Status as of 2026-10-08:** the GitHub repository is already **PUBLIC**, with the 160 original recordings tracked in its current history. The owner explicitly authorized a public academic repository and public recordings, metadata, renders and results. Local research and site validation are available. This change has not deployed a production site, assigned a new license, registered a DOI, or associated participant names with biometric records.
