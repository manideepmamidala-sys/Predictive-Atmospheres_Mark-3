# Experimental room-coordinate model card

**Status:** `not_better_than_baseline`. This is a retrospective demonstrator for the Predictive Atmospheres pilot, not a validated predictor of emotion, health, comfort, or architectural quality. It estimates two **constructed signed coordinates** from room metadata and computes a user-target distance score. Its intended use is to inspect the analysis workflow and its limitations in the research site.

## Data and target

The primary training cohort has 14 Experiment 3 room-viewing trials from three participants and ten rooms. Each included trial has supplied full room attributes, original valence/arousal ratings, and operationally eligible approximate bilateral-forehead and wrist ECG features at a **conditional unconfirmed 500 Hz** time base. Among the other Experiment 3 trials, 24 lack both HR and RMSSD, and 22 lack RMSSD alone. Experiments 1 and 2 were excluded from this full-attribute model. No baseline, confirmed acquisition filter/reference/unit or measured headset light exposure is available. Repeated participant/room identity and protocol differences limit generalization.

The target is a declared population construction: training-partition median/MAD transform of forehead log-alpha asymmetry, log beta/alpha, HR and log RMSSD; `tanh` maps components into signed coordinates. A constructed objective coordinate is mixed at α=0.5 with original signed ratings. This is not observed emotional ground truth. Descriptive within-person normalization and partial-modality records are **never** passed to the model. Missing/nonfinite components leave a trial or fold unavailable rather than receiving neutral or nominal values.

## Training and evaluation

The feature pipeline uses the one declared `RoomInput`/feature builder, training-fitted numeric imputation/indicators and scaling, and training-fitted categorical encoding. Room and subject `LeaveOneGroupOut` answer separate holdout questions. Three-fold inner group selection refits both target and feature transforms inside every training partition. The frozen candidate list contains median/mean baselines, three Ridge penalties and four bounded 100-tree RandomForest settings. Ties favor the simpler candidate within 1e-6 of the global minimum. Final full-data room-group inner selection chose 100 trees, maximum depth 2 and minimum leaf 3. No outer score selected the final configuration.

Held-out-room grouped equal-axis MAE is **0.4304**, versus **0.4099** for the median baseline and 0.4241 for the mean baseline. Thus the selected procedure is worse than a simple median baseline on this observed room holdout. Held-out-subject grouped MAE is 0.4272, equal to median baseline because each outer training partition contains only two participant groups and the frozen rule fixes the baseline instead of tuning. The evaluation contains ten room and three participant folds, no unavailable outer folds, and no confidence interval or demonstrated new-person advantage. [Fold-level memberships, candidate scores and exclusions](../artifacts/results/model_evaluation.json) are retained. This is too small and dependent a cohort for deployment-performance claims.

## Inference contract

The artifact is a trusted local fitted scikit-learn pipeline at `artifacts/model/model.joblib` with `metadata.json`. No fitting occurs at API startup or request time. The metadata records feature order, target calibration, training IDs, grouped metrics, model status, package versions, data/specification/decisions/lock/pyproject hashes, a deterministic Python source-tree hash, a model-file hash, and whether the repository source snapshot is committed. `base_git_revision` identifies only the repository base when local implementation changes are uncommitted; it does **not** claim that legacy HEAD reproduces the model. The loader rejects missing or incompatible metadata, code/data/spec/lock changes, and modified model bytes before trusted deserialization. Never load an untrusted joblib file.

Prediction returns raw and coordinate-clipped values separately. The fixed Neuro-Score is `clip(1 − distance(predicted_point, user_target)/sqrt(8), 0, 1)`; it is a mathematical display convention, not an empirical well-being score. Physical room validity and empirical neighborhood support are separate. The seeded optimizer considers only bounded independent room inputs in observed support, can return no candidates, and reports support distance. No calibrated interval, confidence percentage or personal response guarantee exists. If the artifact is absent/incompatible, `/v1/health` stays live with `ready=false`, while prediction/optimization return structured unavailable errors.

## Known limitations and update policy

Operational EEG epoch acceptance does not remove persistent ocular/motion/muscle contamination; a visual review found bilateral low-frequency transients in accepted windows. ECG accepted intervals are automated approximations rather than verified normal-to-normal beats; only 18 of 160 trials meet the primary 30-second RMSSD rule. Alternative conditional sample rates change eligibility materially. Original ratings and room simulation fields lack independent exposure validation. All scientific settings and the weak-model status must remain visible in any presentation. New acquisition evidence or method changes require an append-only decision amendment, affected reruns, grouped reevaluation and an updated card.
