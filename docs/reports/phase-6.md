# Phase 6 — bounded room search and support

Date: 2026-10-08. The shared `pa.optimize.search` samples only the independent `RoomInput` fields within supplied Experiment 3 marginal ranges, rejects physical invalidity, and then checks an observed multivariate neighborhood. The neighborhood threshold is the 95th percentile of each observed room's nearest-other-room standardized distance, **not** a calibrated probability or guarantee of response. An exact observed room has distance zero. Candidates are deduplicated by the full independent-input tuple and ranked by the one fixed user-target Neuro-Score. Space type and day/night constrain candidates but never select the emotional target. Search uses a declared seed, budget and candidate cap; no model refitting occurs.

After the D-011 amendment, support uses all eleven observed numeric room inputs, including door and window counts. Missing opening counts yield unavailable support; out-of-range counts yield outside range. The recalculated leave-one-room threshold is 1.4063 for this data and method. The physical validity check is independent.

The actual fitted artifact is labelled `not_better_than_baseline`. A representative local call `pa optimize 0 0 --budget 100 --n-candidates 3 --seed 2718` returned three distinct physically valid, empirically supported candidates after evaluating 46 supported configurations. The first two are original observed rooms; the third is a sampled room nearest `Rm_029` at standardized distance 0.545, below the amended observed-neighborhood threshold 1.406. Their displayed scores were 0.9827, 0.9763 and 0.9749 for the **user-selected mathematical target (0,0)**. These scores do not validate architectural quality, comfort or well-being; held-out-room model MAE is worse than the median baseline. The candidate list is an exploratory interface example, not a design recommendation.

`pa optimize 0 0 --budget 100 --n-candidates 3 --seed 2718 --space-type General` returned `status=empty`, `samples_evaluated=0`, an empty candidate list and `no studied room has the requested categories`. A missing/incompatible artifact returns an explicit unavailable state; requests outside configured budget/candidate limits fail validation. Synthetic tests exercise deterministic identity, physical/support validity, deduplication and empty/unavailable behavior. The live API uses the same function and exposes support status, nearest observed room and standardized distance for each prediction/candidate.
